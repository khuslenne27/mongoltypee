# MONGOLTYPE — Next.js + Django v2

## Windows дээр асаах
ZIP-ийг **шинэ хавтаст** задлаарай. Өмнөх төслийн database руу хуулж солихгүй. Энэ багц шинэ initial migration-тай, тусдаа database үүсгэнэ.
Python 3.12+, 64-bit Node.js 20.9+ шаардлагатай.

Хялбар арга: үндсэн `mongoltype-fullstack` хавтас дотор terminal нээгээд:
```powershell
powershell -ExecutionPolicy Bypass -File .\start-backend.ps1
```
Шинэ terminal дээр:
```powershell
powershell -ExecutionPolicy Bypass -File .\start-frontend.ps1
```
Энэ execution policy зөвхөн тухайн process-д үйлчилнэ; системийн тохиргоо өөрчлөхгүй.
Хоёр terminal-ийг нээлттэй үлдээгээд http://localhost:3000 нээнэ.
Backend асаах скрипт dependency суулгана, migration хийнэ, үгс оруулна. Давтан ажиллуулахад үгийг давхардуулахгүй.

## Хийгдсэн өөрчлөлт
- Монгол бичгийн үгийг задлахгүй DOM Range ашиглан дундах бичилтийн байрлалд хөндлөн cursor харуулна. Англи, кириллд босоо cursor.
- Текстийг үг бичих бүрд slice хийж солихгүй. Бүх эх DOM-д тогтвортой үлдэнэ. Мөр/багана солигдоход viewport нэг мөр/баганаар шилжинэ. Backspace хийхэд буцаж харагдана.
- Хугацаагаар: 15, 30, 60, 120 секунд. Үгийн тоогоор: 10, 25, 50, 100 үг.
- Хэл тус бүрд: энгийн үг, цэг/тэмдэгт, тоо, холимог. Монгол бичигт U+1802/U+1803 зэрэг цэг тэмдэг ашиглана. Монгол бичгийн тоо/холимог дасгалд U+1810–U+1819 буюу ᠐᠑᠒᠓᠔᠕᠖᠗᠘᠙ цифр ашиглана; кирилл, англид 0–9 хэвээр. Сайтын гар асаалттай үед 0–9 болон Numpad-аас монгол цифр оруулна. Shift-ийн цэг тэмдэг хэвээр.
- Эхний оролтоос хугацаа эхэлнэ; ESC болон restart товч шинэ дасгал авна.
- Босоо бичгийн доорх keyboard: 2 Windows layout, Shift түвшин, physical code дээр даралтын өнгө, дараагийн үсгийн тэмдэглэгээ, дэлгэцийн товчоор input.
- Үр дүн backend-д хадгалагдана. Түүхийг хэл, горим, ангиллаар шүүнэ. Profile-ийн график нь бодит сүүлийн шалгалтууд.
- Чансаа: хэл тус бүрийн 30 секунд, энгийн үг, хянагдсан сангийн үр дүнгээр бүртгэлтэй хэрэглэгчийн бүх төхөөрөмжийн шилдэг оноог нэгтгэнэ. Зочныг браузераар ялгана. Demo босоо бичгийн үр дүн чансаанд орохгүй.

## Монгол бичгийн гар
Монгол бичгийн дасгалд **Сайтын гар ашиглах** анхнаасаа асаалттай. Энэ үед зөвхөн бичих талбар дээрх физик товчийг сонгосон layout-аар хөрвүүлдэг тул компьютерийн болон дэлгэцийн товч ижил Unicode үсэг оруулна. Системийн гарын байрлал эгшгийн кодыг сольж оруулахгүй. IME ашиглаж байгаа бол English гар сонгох, эсвэл сайтын гарыг унтрааж өөрийн IME-гаар бичих боломжтой. Composition болон Ctrl/Alt/Meta shortcut-уудыг хөрвүүлэхгүй.

Ижил дүрстэй О/У, Ө/Ү-г тусдаа Unicode үсэг хэвээр шалгана. Эгшиг бүр кирилл нэртэй, дараагийн товч нь `Q`, `V`, `O`, `U` гэх мэтээр харагдана. Буруу эгшиг оруулбал яг ямар үсэг орсон болон юу хэрэгтэйг тайлбарлана. Сайтын гарын Backspace нь FVS-ийг дангаар нь арилгаж засах боломжтой.

Төхөөрөмжийн OS гарын байрлалтай ижил нэрийг dropdown-оос сонго:
- Windows Traditional Mongolian (Standard)
- Windows Mongolian (Mongolian Script)
Байрлалын эх сурвалж: https://unicode.org/cldr/charts/43/keyboards/layouts/mn.html (Unicode CLDR 43).
Энэ keyboard OS байрлалыг өөрчилдөггүй. OS гаргүй бол дэлгэцийн товчоор бичиж болно. Shift-ийг дэлгэц дээр дарж нэмэлт үсэг харуулна. Caps Lock/AltGr-ийн тусгай давхарга дэмжээгүй. FVS1/2/3, MVS, NNBSP, ZWJ, ZWNJ харагдах нэртэй.
Стандартын түүхэн хувилбарууд өөр байж болно; өөр layout (MNS, Keyman гэх мэт) ашигладаг бол зураглалын өгөгдлийг тусад нь нэмэх шаардлагатай.
Фонт: Noto Sans Mongolian, SIL OFL (@fontsource). Үсгийн залгалтыг хадгалахын тулд босоо бичгийн зөв/буруу өнгө бүхэл дууссан үг дээр өөрчлөгдөнө; үгийн дундах байрлалыг cursor дагана. Grapheme ба ligature-ээс шалтгаалан тусдаа key бүрд харагдах cursor зай адилгүй байж болно.

## Үгийн сан ба Admin
Кирилл дасгал нь `bataak/dict-mn` зөв бичгийн толийн төсөлд багцалсан хувилбараас үгээ авна. `setup_typing` нь сүлжээ шаардахгүйгээр уг санг импортлоно. Одоо байгаа database-д зөвхөн сан оруулах бол `python manage.py import_dictionary` ажиллуулна. Давтан импорт давхар үг үүсгэхгүй, өмнөх үр дүнг хадгална. Эх сурвалжийн хувилбар, MPL-2.0 лиценз, шүүлтийн дүрэм нь `backend/data/dict-mn/` дотор бий. `verified` нь энэ импортын хувьд тольд бүртгэлтэйг илэрхийлнэ; төрийн баталгаажуулалт гэсэн үг биш.

Босоо монгол бичгийн дасгал нь Khudam төслийн Wiktionary-д тулгуурласан хэсгээс сонгосон **1,504 ялгаатай бичлэгтэй** сан ашиглана. Машин хөрвүүлсэн, хянагдаагүй хэсгийг оруулаагүй. Эх сурвалж, үг тус бүрийн холбоос, CC BY-SA 4.0 лиценз нь `backend/data/khudam/` дотор бий. `setup_typing` автоматаар импортлоно; тусад нь `python manage.py import_mongolian` ажиллуулж болно. Frontend эхлээд босоо бичгийн дасгалыг нээнэ.

Тольд тулгуурласан нь бүх үгийг хүн нэг бүрчлэн баталгаажуулсан гэсэн үг биш. Эх санд хүний хяналттай ганц бичлэг бий; бусдын `verified=false` төлөвийг хадгалсан. Энэ сангийн дасгалын үр дүн хадгалагдах боловч чансаанд орохгүй. Admin-аар үг тус бүрийг цааш хянаж баталгаажуулж болно. Англи нь одоогоор хөгжүүлэлтийн жижиг сантай.
```powershell
cd backend
.\.venv\Scripts\python.exe manage.py createsuperuser
```
http://127.0.0.1:8000/admin/ — үг, verified, эх сурвалж, тест, үр дүн удирдана.
CSV UTF-8: `text,cyrillic,verified,source`.
```powershell
.\.venv\Scripts\python.exe manage.py import_words words.csv --language mn-Mong
```
CSV импортод хүн хянасан зөв бичлэгт л verified=true өгнө. FVS/MVS/NNBSP-г устгахгүй. Private-use legacy кодчиллыг хориглоно. Гаднын өгөгдлийн лицензийг баримталж, эх сурвалж тэмдэглэ. Frontend `demo:false` ашигладаг тул хянагдсан сан оруулмагц дасгалд ашиглагдана.

## Backend, өгөгдөл
Профайлын ахиц: `GET /api/progress` нь хамгийн сүүлийн шалгалтын тохиргоог сонгоно. `language`, `mode`, `category`, `amount`, `demo` query-гаар ижил тохиргоог сонгож болно. Хувийн дээд амжилт, дундаж, нийт тоо нь бүх тохирох түүхээс тооцогдоно; сүүлийн хоёр шалгалтын зөрүү, сүүлийн 5/өмнөх 5 дундаж, 10 үр дүнгийн график, 50 үр дүнгийн хүснэгт харуулна. Хэл, хэмжээ, сангийн төлөв өөр шалгалтуудыг хольж харьцуулахгүй.

Алддаг үсэг/үгийн шинжилгээ нь хадгалсан эцсийн бичвэр дээр үг тус бүрийн grapheme дарааллыг харьцуулна. Дууссан үгийн дутуу үсгийг тоолно; хугацаа дуусахад бичээгүй үлдсэн эх болон идэвхтэй үгийн бичиж амжаагүй төгсгөлийг алдаа гэж үзэхгүй. Илүү үсэг орсон үгийг алдаатай үгт тоолох ч бичих ёстой байсан үсгийн жагсаалтад хиймэл алдаа нэмэхгүй. Засаж арилгасан алдааг энэ шинжилгээ тоолохгүй. Монгол бичгийн FVS/MVS зэрэг нь grapheme-дээ хадгалагдана.

Local хурдан асаахын тулд SQLite. PostgreSQL ашиглах бол backend/.env.example-ийн хувьсагчдыг process environment-д тохируул. Backend .env-ийг автоматаар уншихгүй. Node .env.local дахь DJANGO_API_URL-ээр backend хаягийг сольж болно. Next.js /api хүсэлтийг Django руу proxy хийнэ.
API: POST /api/tests; POST /api/tests/{uuid}/start; POST /api/results; GET /api/history; GET /api/leaderboard?language=mn-Cyrl.
Зочны дасгалууд серверээс олгосон UUID бүхий signed HttpOnly, SameSite=Strict cookie-д хамаарна (production-д Secure). Client-ийн X-Visitor-ID header нь шинэ дасгалын эзэмшлийг тогтоохгүй. Хуучин UUID түүхийг зочны горимд header-аар уншиж болох ч хуучин үр дүн чансаанд орохгүй, зөвхөн UUID мэдэж байгаа нь түүнийг account-д эзэмших баталгаа биш тул автоматаар холбохгүй.

## Нэвтрэх ба бүртгүүлэх
`/register`, `/login` хуудсаар нэвтрэх нэр, нууц үгээр бүртгүүлж/нэвтэрнэ. Django session authentication, password hashing/validation болон CSRF хамгаалалт ашиглана. Нэвтрэх нэр том/жижиг үсэг ялгахгүй; нэр нь чансаанд ил харагдана. API: `GET /api/auth/me`, `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`. `/auth/me` CSRF token өгнө; POST-д X-CSRFToken болон cookie илгээнэ. Login/register token ба session-ийг шинэчилнэ. Нэвтрэх/бүртгүүлэх оролдлого IP бүрд 10/мин хязгаартай.

Signed browser cookie-оор эзэмшил нь батлагдсан, хэн нэгний account-д холбогдоогүй зочны дасгалууд login/register үед тухайн account-д нэг удаа холбогдоно. Нэвтэрсэн бүх төхөөрөмжийн түүх, ахиц, чансаа account-аар нэгтгэгдэнэ. Logout үед session цэвэрлэж, шинэ зочны cookie олгоно; өмнөх account-ийн түүх харагдахгүй. Өөр account-д нэвтрэхийн өмнө logout хийнэ. Email баталгаажуулалт, email-аар нууц үг сэргээх энэ хувилбарт ороогүй; админ `manage.py changepassword <username>` ашиглаж болно.

Frontend секунд тутам `/api/tests/{uuid}/checkpoint` руу одоогийн бичвэр, дарааллын дугаар илгээнэ. Backend серверийн хүлээн авсан цагаар тасралтгүй байдал (4 секундээс их завсаргүй), өөрчлөлтийн хэмжээ (секундэд 35 grapheme хүртэл, жижиг burst зөвшөөрнө), дараалал, эцсийн текстийн тохирлыг шалгана. Чансаанд зөвхөн 30 секунд/энгийн үг/хянагдсан сангийн, серверийн хугацаагаар тооцсон, 80%+ нарийвчлалтай, 0–220 WPM үр дүн орно. Өмнөх шалгалтуудад migration `rank_eligible=false` өгнө. Энэ нь хуурамч эцсийн текст/хугацаа шууд илгээхийг хязгаарладаг боловч бодит хэмнэлээр хүсэлт явуулдаг ботыг хүнээс ялгахгүй; албан ёсны тэмцээний баталгаа биш. Rate limit нь local cache/IP дээр хэвээр тул production-д shared cache шаардлагатай.

`/start` бүтэлгүйтвэл frontend rejected Promise-ийг цэвэрлэж дахин оролдоно. Эхлэх цаг серверт анх удаа сэргээгдсэн бол `recovered_start=true` болгож, үр дүнг зөвхөн дадлагад хадгална. Сервер өмнөх `/start`-ийг авсан ч response тасарсан бол эхлэх цагийг өөрчлөхгүй. Result retry idempotent; давхар даралт нэг хүсэлт ашиглана. API хүсэлт 10 секундийн timeout-тай.

## Оноо
WPM = зөв grapheme cluster / 5 / минут. Accuracy = одоо байгаа текстийн зөв cluster / нийт cluster. Үг бүрийг тусдаа харьцуулдаг тул нэг үгийн илүү тэмдэг дараагийн үгсийг буруу болгохгүй. Засч арилгасан алдааг хуримтлуулдаггүй. Хэлбэр сонгогчийг base үсэгтэй нэг cluster гэж тоолно. Backend regex \\X ба frontend Intl.Segmenter нь Unicode хувилбараар зөрөх магадлалтай; хадгалсан backend үр дүн эцсийнх.
Үгийн горим сүүлийн үгийн уртыг хүрэхэд дуусна (алдаатай байсан ч дуусч болно). Хугацааны горим 600 үгийн эхийг ашигладаг; эхийг бүхэлд нь дуусгавал эрт дуусна. Үгийн горимын дээд хугацаа 60 минут.

### v2.1 — Монгол бичгийн шууд шалгалт
Идэвхтэй үгийн typed grapheme бүрийн зөв/бурууг ногоон/улаан давхаргаар шууд өнгөлнө. Бүхэл үгийг давхар зурж glyph range-аар clip хийдэг тул үндсэн текстийг үсэг тус бүрээр таслахгүй, залгалтыг хадгална. Scroll баганыг үсгийн хэлбэрийн хайрцгаас бус тогтвортой үгийн баганаас тооцно; зай авахад нэг баганад хэвээр байвал viewport хөдлөхгүй.
